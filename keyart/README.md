# 키 아트 시안 (동해)

게임 화풍과 동해 레벨의 기준이 되는 그림입니다. 게임 화면에서 불러오지 않는 참고 자료입니다.

- `character_sheet.webp` — 캐릭터 기준 시트 (티셔츠 / 장화 / 웨이더)
- `01_world.jpg` — **전체 전경** (레벨 배치의 기준)
- `02`~`12` — 해수욕장, 파도 치는 해변, 스노클링 갯바위, 절벽 동굴·산책로, 절벽 위 정자, 해안 데크길, 방파제·등대, 소나무숲, 유채꽃밭, 몽돌해변, 해안기차
- `13_pebble_dusk.jpg` — 몽돌해변 해질녘
- `14_coastal_hill.jpg` — 해안 언덕 (여럿이 걷는 넓은 길), `14b_coastal_hill_path.jpg` — 같은 장면의 다른 안
- `v1/` — 첫 번째 캐릭터로 만든 시안 중 선택한 7장

규칙: 테트라포드·방파제·등대는 항상 육지와 이어지게 그립니다.
